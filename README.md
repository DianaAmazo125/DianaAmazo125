### 🎬 video-montage — автоматический монтаж видео

Движок берёт один видеофайл и сам делает из него готовый ролик: распознаёт речь, вырезает паузы
и «воду», оставляет самые плотные фрагменты, добавляет заголовок, пословные субтитры, главы
и финальную карточку. На выходе обычный `mp4`.

Собирает всё в цепочку: `ffmpeg` режет и клеит звук, `faster-whisper` распознаёт речь,
Remotion рендерит картинку с титрами, а режим `--ai` отдаёт отбор фрагментов нейросети.
Проект рассчитан на Windows, запускается одной командой `montage.cmd`.

### 🔎 AI_scout — мониторинг Telegram-источников

Сервис следит за выбранными Telegram-чатами: слушает сообщения, отбрасывает пересылки и сообщения
ботов, складывает остальное в SQLite с защитой от дублей и печатает карточки с автором и ссылкой
на сообщение. Задуман как помощник для поиска заказов: ИИ готовит черновик отклика, а решение
и отправку оставляет человеку.

Сейчас реализован первый этап — сбор и хранение сообщений; фильтры и работа с ИИ описаны
в конфиге, но ещё не подключены. Честно указано в README проекта.

### 🌌 digest_site — сайт-каталог нейросетей

Сайт-дайджест нейросетей и сервисов, доступных в России без VPN. Все карточки лежат в одном
JSON-файле, поэтому каталог обновляется правкой данных, а не кода: добавили объект — появилась
карточка и кнопка её категории. Есть живой поиск, фильтр по темам, счётчик найденного,
поддержка партнёрских ссылок и плашка маркировки рекламы `erid`, а также места под рекламные
блоки Яндекс.РСЯ.

### ✍️ post_generator — генератор постов для соцсетей

Веб-панель, которая превращает сухие данные о товаре в готовый продающий пост.
Заполняете название, описание и цену, выбираете одну из шести тональностей — текст пишет
нейросеть, вы правите его руками и публикуете в сообществе ВКонтакте прямо из интерфейса.
Если ИИ недоступен, включается резервный шаблонный генератор, чтобы панель не осталась пустой.

### 🤖 telegram_bot — ИИ-ассистент в Telegram

Бот отвечает на сообщения с помощью нейросети, помнит контекст последних десяти сообщений,
показывает статус «печатает…» и аккуратно режет длинные ответы под лимит Telegram.
Умеет работать через локальный прокси, если Telegram API недоступен напрямую.

## Технологии, с которыми работаю

- **Язык и бэкенд:** Python, Flask, Jinja2, REST API, работа с JSON-данными
- **Фронтенд:** HTML, CSS, JavaScript, Bootstrap — без сборщиков, там где они не нужны
- **ИИ:** OpenAI-совместимые API, DeepSeek, работа с промптами; шлюз ProxyAPI для оплаты в рублях
- **Боты и данные:** Telegram Bot API, Telethon, SQLite, pydantic
- **Медиа:** ffmpeg, faster-whisper, Remotion
- **Инструменты:** Git и GitHub, python-dotenv, pytest, ruff
